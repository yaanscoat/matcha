## Local

Copy these commands into your terminal

>[!IMPORTANT]
>Git and the latest version of NodeJS/npm or bun is needed.

```sh
git clone https://github.com/yaanscoat/matcha

cd matcha

npm i      #npm install script
npm start  #basic nodejs server
```
